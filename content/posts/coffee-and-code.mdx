## 修了一个奇怪的 Bug

今天花了两小时排查一个前端问题：页面在某些情况下会闪一下白屏。

最后发现是 `useEffect` 的依赖数组少了一个变量，导致组件在不需要的时候重新渲染。

**教训**: 永远相信 ESLint 的 `exhaustive-deps` 提示。

改完之后的代码简洁多了：

```tsx
useEffect(() => {
  if (data) {
    setState(transform(data));
  }
}, [data]); // ← 就是这个 [data] 忘了写
```
