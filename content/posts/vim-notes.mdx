## 前言

用了 Vim 三年，回头看看，真正让我效率变高的不是那些花哨插件，而是**刻进肌肉记忆的基本操作**。

## 基础移动（已经不用过脑子）

- `h` `j` `k` `l` — 左 下 上 右
- `w` / `b` — 按单词前后跳
- `0` / `$` — 行首/行尾
- `gg` / `G` — 文件头/尾

## 让我爽到的组合

### 删除一个单词并进入插入模式

```
ciw
```

这个的意思是 **c**hange **i**nner **w**ord——先删掉光标所在的单词，然后自动切到插入模式，等着你打新内容。

### 选中括号里的所有内容

```
vi(
```

**v**isual select **i**nner **(**parentheses)**。把 `(` 换成 `{`、`[`、`"` 都行。

### 在下一行插入空行

```
o
```

大写 `O` 是在上一行插入。对我这种写 Markdown 频繁换行的人来说，这个太重要了。

## 搜索和替换

```vim
/pattern        " 搜索
n / N           " 下一个 / 上一个
:%s/old/new/g   " 全文替换
```

## 最后

Vim 的学习曲线确实陡，但过了那个坎之后，你会**无法忍受用普通编辑器写代码**。

> 人生苦短，用 Vim。
