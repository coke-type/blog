## 为什么要自己搭博客？

市面上有那么多博客平台——Medium、Substack、知乎专栏……但我还是选了**自己搭**。原因很简单：

- 完全掌控自己的内容
- 可以写 MDX，在文章里嵌 React 组件
- 主题想怎么改就怎么改
- 顺便练练 Next.js 16

## 技术选型

这次用的是:

| 技术 | 用途 |
|------|------|
| Next.js 16 | 框架 |
| MDX | 文章格式 |
| Tailwind CSS | 样式 |
| TypeScript | 类型安全 |

## 一个小贴士

写 MDX 的时候，**frontmatter** 很重要——它是每篇文章的元数据：

```yaml
title: "文章标题"
date: "2026-05-22"
tags: ["标签1", "标签2"]
excerpt: "一句话摘要"
```

就这样，第一篇博客写完啦。后面会陆续记录更多内容 🚀
